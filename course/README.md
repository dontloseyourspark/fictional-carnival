# Build the ORÉE website

A 10-lesson beginner course. Students build the ORÉE jewellery website from a blank page, using only HTML and CSS. No experience is needed.

## Lessons

| # | Lesson | Students finish with |
|---|---|---|
| 1 | What is a website? | The four parts of a website, written by hand in Notepad |
| 2 | Pictures, links and a proper skeleton | A photo, working links, and a name in the browser tab |
| 3 | Fill in the whole page | Every section of the page, unstyled |
| 4 | Meet CSS: colour and type | The page starts to look like ORÉE |
| 5 | Space and boxes | A tidy page with breathing room |
| 6 | The header and hero | The top of the page matches the design |
| 7 | Cards and grids | The collection and bestseller sections |
| 8 | Finish the design | A complete desktop page |
| 9 | Make it work on phones | A page that works on their own phone |
| 10 | Contact form and going live | A live website with a working form |

## What's in each lesson folder

- **outline.md** — the recording guide: what to show, what to say, the student task, and common problems.
- **start/** — the files students begin with (the previous lesson's result).
- **finished/** — what the page should look like at the end, for students to compare against.

The photographs are in [resources/images/](resources/images/). Students copy them into their own project when a lesson needs them.

The finished website this course builds towards is in the main project folder, one level up.
