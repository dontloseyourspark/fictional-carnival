# Build the OREE website

A beginner course. Students build the OREE jewellery website from a blank page, using only HTML and CSS. No experience is needed.

Each lesson introduces one or two new ideas and runs about 10–12 minutes. Going slowly is the point: every lesson ends with something visible that works.

The course writes the name as **OREE**, without the accent, because typing É is fiddly on most keyboards. The finished website keeps ORÉE.

## Lessons

### Part 1: HTML, the structure

| # | Lesson | New ideas | Students finish with |
|---|---|---|---|
| 1 | What is a website? | The four parts of a website · what HTML is · `.html` files | Their first webpage, written in Notepad |
| 2 | Your first tags | Opening and closing tags · `<h1>`, `<h2>`, `<p>` | Headings and paragraphs for the four parts |
| 3 | A proper skeleton | Sublime Text · `<!DOCTYPE>`, `<head>`, `<body>`, `<title>` · tags inside tags | A properly structured page, named in the browser tab |
| 4 | Adding a photo | Folders · `<img>`, `src`, `alt` · file paths | The ring photograph on their page |
| 5 | Grouping the page | `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` · headings in order · comments | The four parts, properly labelled |
| 6 | Lists and links | `<ul>`, `<li>` · `<a>`, `href` · email and web links | Navigation that works as links |
| 7 | Fill in the whole page | Reusing patterns · `id` and jump links · `<blockquote>` | Every section of the page, unstyled |

**Bonus chapter:** JavaScript, starting with the mobile menu.

## What's in each lesson folder

- **outline.md** — the recording guide: what to show, what to say, the student task, and common problems.
- **start/** — the files students begin with (the previous lesson's result).
- **finished/** — what the page should look like at the end, for students to compare against.

The photographs are in [resources/images/](resources/images/), and every word on the page is in [resources/page-text.txt](resources/page-text.txt). Students copy from these when a lesson needs them.
